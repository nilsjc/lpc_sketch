# LPC experiments with C# on .NET
This is a console program that will generate synthetic speech based on a soundfile with speech.<br>
For now this sound quite Lofi, but i am anyway more interested in using this in a musical application.<br>
If you want to, you can omit pitch detection and sound like a robot.<br>
This is an work in progress and some features is not working, like changing the formants.<br>
In the future this will be converted to a MCU instead. And it will work in realtime, not rendered. Until then, this project is my test platform.<br>
Have fun...
