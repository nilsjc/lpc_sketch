# LPC experiments with C# on .NET
This is a console program that will generate synthetic speech based on a soundfile with speech.<br>
When you start, it will ask for a file and some user input like formant or pitch shifting, or if you want your speech sound more like a robot/vocoder. It will then generate a result.wav file<br>
For now this sound quite Lofi, but i am anyway more interested in using this in a musical application.<br>
This is an work in progress and some features is not implemented, like time stretch, external source modulation or control. The formant shift is a bit shaky as well.<br>
A GUI would also be nice to have, with some sound playing capabilities.<br>
In the future this will be converted to a MCU instead for use in a modular synthesizer. It will then work in realtime, not rendered.<br>
Until then, this project is my test platform.<br>
Have fun...
